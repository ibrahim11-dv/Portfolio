# Third-party assets

## Loupe application icon

`public/ubuntu-apps/loupe.svg` is the unmodified application icon from the GNOME Loupe 50.0 release, `data/icons/hicolor/scalable/apps/org.gnome.Loupe.svg`.

Source: https://download.gnome.org/sources/loupe/50/loupe-50.0.tar.xz

The accompanying upstream license is retained in `public/ubuntu-apps/loupe.LICENSE.md`. The viewer implementation in this project was written independently using Loupe's published interface as a design reference.
