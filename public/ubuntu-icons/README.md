# Yaru Icons

Original, unmodified symbolic icons from Ubuntu Yaru, release `26.04.5.1ubuntu`.
Source: https://github.com/ubuntu/yaru/tree/26.04.5.1ubuntu/icons/Yaru/scalable

Attribution: Yaru Icons — http://snwh.org/
License: CC BY-SA 4.0 (see COPYING and https://creativecommons.org/licenses/by-sa/4.0/).
The Wi-Fi excellent and battery level 100 filenames resolve the upstream symlinks
to network-wireless-connected-symbolic.svg and devices/battery-symbolic.svg.

The app uses CSS masks to display these icons in the panel foreground color.
